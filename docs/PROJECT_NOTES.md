## 当前定位

China GLP-1 HOT 是一个中国优先的 GLP-1 新闻时间线。它只展示中国市场相关内容，优先保留严肃信源和高价值事件，并通过五维评分、代码精选和事件聚类减少重复信息。

旧版 GLP-1 舆情看板保留为独立模块，可从左侧功能菜单进入。

- `index.html`：新闻首页。

- `docs/PROJECT_NOTES.md`：本项目记录文档。

## 前端功能

- 首页品牌名：`China GLP-1 HOT`。
- 顶部支持“精选 / 全部”切换。
- 支持搜索标题、摘要、公司、药物。
- 主题筛选为横向可滑动单选按钮。
- 新闻按发布时间降序展示，时间统一为 24 小时制。
- 前端日期和时间固定按北京时间显示。
- 时间线支持按天收起和展开，桌面端和移动端共用同一套交互。
- 文章标题点击后跳转到原始新闻链接。
- 五维分数压缩为单行展示，移动端使用短标签。
- 相关报道折叠在主条下，按钮显示相关报道数量。
- 明暗模式可在侧栏底部切换。
- 移动端使用抽屉菜单，点击 `X` 或右侧遮罩关闭。
- 桌面端正文占满可用宽度，不再居中限制为窄列；左侧菜单可通过 `X` 收起，再通过左上角菜单按钮展开。
- 功能菜单包含：新闻首页、评分机制、舆情看板。

## 数据流程

1. 从 `scripts/sources.yml` 配置的 RSS/新闻源抓取条目。
2. 用 GLP-1 关键词做初筛。
3. 解析标题、摘要、来源、发布时间、地区、主题、公司/药物/事件标签。
4. Google News 聚合源只作为发现入口；解析出原文链接后，会优先从原文页提取站内发布时间，并用原文发布时间做时间窗口过滤。
   - 中文原文页如果只写 `YYYY-MM-DD HH:mm:ss` 且没有时区，按北京时间理解。
5. 调用 DeepSeek 评分；如果没有 API key，则使用规则评分兜底。
6. 代码计算最终质量分。
7. 代码判断是否精选。
8. 用规则做事件聚类，选择主条并折叠相关报道。
9. 输出 `data/news.json` 供静态页面读取。

## 评分机制

大模型只负责给每条信息打 5 个维度分，不计算最终分，不判断精选，不处理来源权重。

五维分：

- `relevance`：GLP-1 相关性。
- `importance`：行业、临床、监管、商业格局重要性。
- `credibility`：可信度与可验证性。
- `freshness`：新闻新鲜度。
- `china_impact`：中国市场影响。

最终质量分由代码计算：

```text
0.25 * relevance
+ 0.25 * importance
+ 0.20 * credibility
+ 0.15 * freshness
+ 0.15 * china_impact
```

加权规则：

- 监管源、公司官网、临床登记、论文源、专业媒体按来源类型加分。
- 中国相关且 `china_impact >= 55` 额外加分。
- 监管审批、临床试验、安全性主题小幅加分。
- 可信度低于 45 扣分。
- 相关性低于 50 扣分。
- 最终分 clamp 到 `0-100`。

精选规则：

- `needs_review` 不精选。
- 来源类型和主题类型各有门槛，取更高者。
- 同时要求 `relevance >= 55` 且 `credibility >= 50`。

## 事件聚类

聚类目标是把同一事件的多源报道折叠为一个主条，避免首页重复。

当前规则：

- 时间窗口：3 天内。
- 主条优先级：来源权威度 > 质量分 > 发布时间。
- 非常具体的事件词可以直接触发聚类，例如“网售限制”。
- 普通大类词如“临床、研究、获批”不能单独触发聚类。
- 一般情况下必须共享同一公司，或共享同一药物并同时满足更高的事件重合要求。

最近修正：

- 之前“临床、研究、获批”等大类词权重过高，导致不同公司、不同药物的 GLP-1 赛道新闻被错误聚类。
- 现在已收紧规则：恒瑞临床新闻只和恒瑞相关报道聚类；礼来相关报道单独聚类；网售禁令/擦边球/纸质处方等属于同一监管执行事件，可以继续折叠。

## 发布与部署

- 线上仓库：`jackson0730/glp1-dashboard`。
- GitHub Pages 站点：`https://sociallisteningdashboard.cn`。
- 当前机器已配置 SSH 推送，后续不需要 GitHub token。
- 已配置 Codex 本地定时任务：每天北京时间 01:30 自动同步 `main`，增量抓取北京时间昨天 0 点到 24 点的新新闻，合并进 `data/news.json`，运行测试，并在只有新闻数据变化时提交和推送到 `origin main`。
- 自动任务只允许提交 `data/news.json`，如果出现其他意外文件改动会停止并报告。
- 如果自动新闻更新需要 DeepSeek 五维评分，需要在运行环境配置 `DEEPSEEK_API_KEY`；未配置时脚本会使用规则评分兜底。
- 如需提交 GitHub Actions 工作流，token 需要 `Workflows: Read and write`；SSH 推送普通代码不需要 token。
